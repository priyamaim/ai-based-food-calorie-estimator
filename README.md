# 🥗 NutriSnap AI - Food Calorie & Nutrient Estimator

NutriSnap AI is a 100% standalone, mobile-first Single Page Application (SPA) that estimates food calories and macronutrients directly from photos using the **Google Gemini API** (`gemini-3.6-flash` model).

Built with React, Next.js (App Router), Tailwind CSS, and the official `@google/genai` SDK.

---

## ✨ Features & Architecture

- 📐 **Two-Column Responsive Dashboard Layout**:
  - **Left Column (Input Panel)**: Interactive drag-and-drop zone with instant thumbnail preview, image removal `(X)` button, camera snap & gallery file picker, auto-compression metrics (>4MB), and high-visibility `Analyze Meal` button.
  - **Right Column (Results Dashboard)**:
    - **Empty State**: Glassmorphism placeholder graphic instructing the user to upload a photo.
    - **Hero Calorie Card**: Prominent total calorie counter with confidence score rating (`High`, `Medium`, `Low`).
    - **Macronutrient Grid**: Visual progress meters for Protein, Carbs, and Fats (grams, calories, percentage ratio).
    - **Itemized Ingredient Breakdown Table**: Structured table listing recognized dish components, estimated weight/portion size (e.g. `150g` or `1 cup`), and individual calorie counts.
    - **AI Health Insights**: Dietary recommendations generated by Gemini AI.
- 📸 **Dual Image Input**: Snap photos via HTML5 media capture or upload from device storage.
- ⚡ **Gemini 3.6 Flash Vision**: Powered by `gemini-3.6-flash` with strict JSON schema response mode.
- 🗜️ **Client-Side Image Auto-Compression**: Automatically compresses images larger than 4MB down to ~1MB high-quality JPEGs before base64 transmission to minimize latency.
- 🔑 **Dual API Key Management**:
  - **Server Proxy**: Protects API keys in production via serverless route `/api/predict` (`GEMINI_API_KEY` in `.env.local`).
  - **User Testing Input**: UI settings modal to input & store a custom Google AI Studio API key in `localStorage`.
- 💾 **Local Meal Log**: Persistent history drawer to review saved meal scans.

## 🔑 How to Get a Free Google Gemini API Key

1. Go to [Google AI Studio](https://aistudio.google.com/app/apikey).
2. Sign in with your Google account.
3. Click **"Create API key"**.
4. Copy your generated API key string (starts with `AIzaSy...`).

---

## 🛠️ Local Setup & Development

### 1. Install Dependencies

```bash
npm install
```

### 2. Configure Environment Variables

Create `.env.local` in the project root:

```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### 3. Run Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🌐 Deploying to Vercel / Netlify

1. Push code to GitHub.
2. Import project into Vercel or Netlify.
3. Add `GEMINI_API_KEY` in **Environment Variables**.
4. Click **Deploy**.
